Vim 速查：模式、查找与批量替换

Vim 模式切换、查找替换与常用命令

一、三种模式#

Vim 打开文件后处于普通模式，此时每个按键都是命令，想打字必须先进入插入模式：

按键作用
i / a在光标前 / 后插入
o / O在下一行 / 上一行新开一行插入
Esc回到普通模式
:进入命令行模式

刚学时最容易犯的错就是「在普通模式里猛敲字」，屏幕只会乱跳。记住 Esc 是万能回退键。

二、移动与编辑#

gg    跳到第一行          G     跳到最后一行
0 / $ 行首 / 行尾         3G    跳到第 3 行
dd    删除整行            3dd   删除 3 行
yy / p 复制整行 / 粘贴     u     撤销      Ctrl+r 重做

dd、yy 这类命令可以叠加数字，3dd 就是删三行——这就是 Vim 的「动作 + 数量」语法。

三、显示行号#

:set nu      " 显示行号
:set nonu    " 取消行号

写配置文件和改脚本时，行号几乎是必须的，报错信息里的行号才好对照。

四、查找与替换#

/Geo          " 向下查找 Geo
?Geo          " 向上查找
n / N         " 跳到下一个 / 上一个匹配
s/旧/新/       " 只替换当前行第一个匹配
s/旧/新/g      " 替换当前行所有匹配
%s/旧/新/g     " 全文替换
2,4s/旧/新/g   " 只替换第 2~4 行

% 表示全文、g 表示一行内所有匹配，两者组合才是最常用的「全局替换」。

小坑：如果之前搜索过别的内容，屏幕上会残留高亮。在 ~/.vimrc 里加一行 set nohlsearch 可以关掉它。

五、保存与退出#

:wq     " 保存并退出
:w      " 只保存
:q      " 退出（有改动时会报错）
:q!     " 放弃修改强制退出

六、为什么值得学#

Vim 的价值在于手不离主键区就能完成全部编辑动作，而且这些动作在 SSH 连接、 服务器运维、容器里都没有图形界面也能用。习惯之后，改配置文件比用记事本快得多。
